 == theory
Reduced model. Each round of rk_loop.py is a map on the push vector v at block b. The per-position push is min(|h_t|, 2 med_b)*v with |v| = alpha. The read-back is d = mean_j (x_j+ - x_j-)/2, where x is the unsteered reader's mean block-b state over the continuation, and F(v) = E[d]. Units: cbar_b = kappa_b*med_b, with kappa_b = the mean over continuation tokens of min(|h_t|, 2 med_b)/med_b (this is where the cap enters). The push per position then has norm alpha*cbar_b, and the read-back is a mean state shift per position in the same space.

(1) Odd by construction. The + and - texts share one Gumbel key, so pushing -v swaps the two texts: delta_j(-v) = -delta_j(v) for every pair, and alpha = 0 gives token-identical texts (both hold exactly in simulation B1; floating-point batch effects are covered by the pilot's CRN-mirror check). P_v(seq) = prod_t softmax(l_t(v)/T)[y_t] is analytic in v, so F(v) = J v + C3[v,v,v] + O(|v|^5). There are no even terms.

(2) Linear response, exact for softmax/Gumbel sampling (likelihood-ratio form of fluctuation-dissipation): J = dF/dv|0 / cbar = (1/(T*cbar)) * Cov_T(x, S), where S = sum_t (dl_t/dv)^T (e_{y_t} - p_t) is the logit score of the sequence. J is the cross-covariance between what the model reads back and how a push tilts its own sampling, with a Curie-like 1/T prefactor.

(3) Loop gain. In the self-fed loop, one round's read-back is the next round's push in the same units: v_{n+1} = F(v_n)/cbar. This is the in-context (KV-cache) form of the loop: the state shift caused by the model's own text is what later tokens see, which links it to RGI's KV-cache case. Secant gains along a direction u at amplitude alpha:
- projected: g_par(alpha,u) = u.F(alpha u)/(alpha cbar), the Rayleigh quotient;
- norm: G(alpha,u) = |F(alpha u)|/(alpha cbar).
At an eigendirection both equal the eigenvalue (in modulus). The zero state is stable iff the spectral radius rho(J) < 1.

(4) Bifurcation. F is odd (Z2-equivariant), so a real eigenvalue crossing +1 gives a pitchfork: two symmetric self-sustained states +-v* (pro and anti stance).
- Normal form along the top mode: a_{n+1} = lambda a_n - c a_n^3, so a*^2 = (lambda-1)/c and G(a*) = 1.
- c > 0: supercritical, soft onset. G falls with alpha, and the critical push alpha* (G = 1) is the self-sustained amplitude.
- c < 0: subcritical, hard onset. G rises with alpha and there is hysteresis: the zero state is stable, but a large enough push tips the loop into self-sustainment. This is the 'runaway' signature.
- lambda = -1: flip. For an odd map the period-2 orbit is {v*, -v*}, i.e. 'RSI begets anti-RSI'.
- Complex pair with |lambda| = 1: Neimark-Sacker. The stance direction rotates, growth is set by |lambda|, and the norm gain, not the projection, decides.
- With a bounded read-back (|F| <= F_max), G ~ F_max/(alpha cbar) at large alpha, so alpha* ~ F_max/cbar.

(5) The loop as actually run (fixed alpha, direction re-derived) is a noisy power iteration on the secant operator J_alpha: d_{n+1} = alpha cbar J_alpha unit(d_n) + noise, with noise norm nu = sqrt(tr Sigma/N).
- Mean-field overlap with the mode: m_{n+1} = L m_n / sqrt(L^2 m_n^2 + nu^2), with L = |F(alpha u*)|.
- Fixed point: m^2 = 1 - nu^2/L^2, which equals rel_n.
- Ordering transition at SNR = L/nu = 1, i.e. rel = 0.5. This is exactly the plan's rel >= 0.5 criterion.
- This persistence line depends on N; the self-sustainment line g = 1 does not. A loop can converge without sustaining itself: in simulation A4, lambda = 0.6 loops reach rel ~0.6.

(6) Noise floor.
- E|d|^2 = |F|^2 + tr Sigma/N, so the naive gain |d|/(alpha cbar) is inflated.
- Unbiased: U = (|sum_j delta_j|^2 - sum_j |delta_j|^2)/(N(N-1)), i.e. |d|^2 minus the sign-flip floor sum|delta_j|^2/N^2 = E|mean_j e_j delta_j|^2.
- A noisy direction u = unit(d_n) has overlap^2 = rel_n with the mode. Attenuation-corrected gains: g_par = unit(d_n).d_{n+1}/(alpha cbar rel_n); G = sqrt(U_{n+1})/(alpha cbar sqrt(rel_n)); rotation cosine = g_par/G.
- For a pooled direction u* with m*^2 = U_pool/|d_pool|^2, divide by m*^2 (projection) or by m* (norm).

(7) What temperature does.
- (a) The 1/T*Cov_T term in J: lambda(T) = chi_T/T. T_c is where rho(J_T) = 1, a Curie-Weiss mean-field criterion (sampled tokens as spins, the push as field, the read-back as coupling).
- (b) T sets the radius of the linear regime, because the push competes with logit gaps of order T. Hypothesis to test (collapse): F_T(alpha) = F_0.7(0.7 alpha/T), i.e. 'temperature = inverse coupling'.
- (c) T raises the sampling noise nu(T), which shifts the persistence line (a noise-induced shift). With jump noise var ~ alpha, the self-fed loop keeps a floor amplitude ~ nu^2/(1-g^2), which diverges as g -> 1 (critical fluctuations).
- (d) T can change which mode is on top. In mechanistic model B (weak coupling), the T = 1.0 top mode has |cos| 0.39 with the T = 0.7 mode and is a complex pair.
- When the read-back saturates, alpha* ~ F_max/cbar is nearly T-independent. In mechanistic model B (tied embeddings), alpha* = 1.01/1.11/1.10 alpha_0 at T = 0.3/0.7/1.0, although lambda_lin = 2.63/2.20/1.50.

(8) TD/Q-learning analogue.
- Linear TD(0)/Q: Q_theta = Phi theta. Expected update theta_{k+1} = theta_k + eta(b - A theta_k), with A = Phi^T D (Phi - gamma P_pi Phi). The error obeys e_{k+1} = (I - eta A) e_k and is stable iff every eigenvalue a_i of A has Re a_i > 0 and eta < 2 Re a_i/|a_i|^2.
- Our loop is full-replacement bootstrapping (eta = 1, fitted value iteration). Iteration matrix M = gamma (Phi^T D Phi)^-1 Phi^T D P Phi; it diverges iff rho(M) > 1. This can happen even though rho(gamma P) <= gamma < 1, because projecting onto the features is not a contraction in P's norm when D is not P's stationary distribution.
- Deadly triad (Sutton & Barto 2018, ch. 11), mapped to our loop: function approximation = the low-dimensional mean-state read-out; bootstrapping = re-derivation from the model's own text; off-policy = the unsteered reader reads steered text it would not have written.
- Known results (cited from memory, not re-checked here): Baird (1995) gives the divergence counterexample; Tsitsiklis & Van Roy (1997) show on-policy linear TD converges; Gordon (1995, 2001) on averagers and chattering; Melo, Meyn & Ribeiro (2008) give conditions for Q-learning with linear features.
- With a Boltzmann policy at temperature tau, the target's Jacobian gains (1/tau)*Cov_pi terms, the same fluctuation term as in J. Asadi & Littman (2017) show the Boltzmann softmax operator is not a non-expansion and that SARSA can have multiple fixed points: a temperature-controlled bifurcation in a bootstrapped update.
- Achiam, Knight & Abbeel (2019) characterise deep-Q divergence by the NTK-weighted update matrix. Its off-diagonal generalisation corresponds to our transfer from a start to the attractor (cos(d1, start) ~ 0 in the earlier block-14 loop).
- L2 regularisation (weight decay) shifts A -> A + lambda I, a restoring 'mass' term with critical lambda_c = -min Re a_i. This is why weight decay is the toy's control parameter.

'Theta' generalised: theta is whatever the system improves from its own output (here the block-b push; in RGI terms weights, the KV cache, or another model). The 'Theta-singular network' is the self-referential map theta -> F(theta). Near theta = 0 its dynamics are set by:
- the geometry J: its eigenvectors are the modes that can sustain themselves, and their alignment with the RSI and GI axes is measurable;
- the control parameters alpha (coupling), T (temperature), N (finite-size noise), and block/delta (which space).
The phase diagram is the sign of log rho(J_{alpha,T}), plus the persistence line rel = 0.5.

Estimated quantities: g_par and G per cell; the free modal gain from the frozen loops; alpha* and the critical damage D*; T_c; lambda_lin by the fluctuation-dissipation estimator; the collapse test; alignment cosines.

 == rule
Qwen, per block b. Frozen before the sweep.
- All intervals are 90%, joint prompt bootstrap with 2,000 replicates, with the same prompts and keys across cells.
- Decision gain = g_par/m*^2 if the corrected rotation cosine is >= 0.9, else the debiased norm gain G/m*.
- u*_b is usable only if m*^2 >= 0.5; otherwise report 'mode not resolved'.

R1 Critical push (alpha series at T 0.7).
- FOUND-soft (supercritical pitchfork): some lower-alpha cell has lower bound > 1 and some higher-alpha cell has upper bound < 1. alpha* = the first downward crossing (log-log interpolation) with its interval, also reported as the critical damage D*.
- FOUND-hard (threshold, hysteresis): upper bound < 1 at a lower alpha and lower bound > 1 at a higher alpha. If both FOUND-soft and FOUND-hard hold, report a bistable window.
- SUB(>= alpha_0): every upper bound is < 1 for alpha >= alpha_0. This reads 'no self-sustaining loop in the tested range'. If the 0.5 alpha_0 cell also has upper bound < 1, report SUB.
- SUPER: every lower bound is > 1, so alpha* > 4 alpha_0.
- Otherwise UNDECIDED.
- Onset type is also judged from the paired difference g(0.5 alpha_0) - g(alpha_0): soft if its interval lies above 0, hard if below.

Simulated properties of R1:
- False FOUND <= 3% when g = 1 everywhere.
- At expected noise with (128, 128, 64, 64) pairs, FOUND for crossings inside [1, 4] alpha_0 in 0.87-0.91 of runs; alpha* interval coverage 0.88-0.92 at a median width factor of about 1.6.
- SUB(>= alpha_0) is reached in 0.89 of runs when true.
- Crossings within a factor 1.5 of the grid edge are mostly UNDECIDED, and hard-onset lower crossings are found only about 0.3 of the time. Both are stated limitations.

R2 Temperature.
- T_c at alpha_0 = the bracket [T_i, T_i+1] when the gain intervals at the two temperatures lie on opposite sides of 1, with a point estimate by linear interpolation in T (simulated coverage 0.86-0.94 when estimable). Otherwise 'no critical temperature in [0.3, 1.0] at alpha_0', with the side stated.
- 'Temperature moves the critical push' if the alpha*(0.3) and alpha*(1.0) intervals do not overlap (censored intervals count); the direction is stated.
- 'Saturation-limited, nearly T-independent' if both are located and overlap.
- Collapse hypothesis ('temperature only rescales the push, F_T(alpha) = F_0.7(0.7 alpha/T)') is rejected if any off-series cell departs from the T 0.7 curve beyond a Bonferroni family-wise 90% interval. Simulated false rejection 0.11-0.15; power 1.0 against an amplitude change at expected noise.

R3 Delta.
- Gamma_b = the decision gain at alpha_0, T 0.7: the free loop estimate pooled with the alpha_0 cell.
- 'Loop gain falls with delta' if Gamma decreases from the lowest-delta to the highest-delta block, with non-overlapping intervals at the two ends and the middle block not above the low block's interval. 'Rises with delta' is the mirror image. Otherwise 'no monotone relation'.
- The same test applies to D*_b (where located at >= 2 blocks) and to g(alpha_0, T) at each temperature.
- Only blocks with SEA PC_PASS and m*^2 >= 0.5 enter. Three blocks cannot separate delta from depth; this is stated with the result.

R4 First mode to go critical, and its alignment.
- The critical mode is the mode with the largest decision gain at the cell nearest g = 1. It is u*_b unless (i) or (ii) below applies.
- (i) The loops converge to different directions (pairwise corrected |cos(d_4)| < 0.5). Then the loop with the highest Gamma is 'first' only if its lower bound exceeds all other upper bounds; otherwise report 'degenerate'.
- (ii) Some cell has rotation cosine < 0.8. Then the Q6 power step defines the mode there, and 'the critical mode changes with T (or alpha)' if its corrected |cos| with u*_b is < 0.7.
- Alignment uses corrected cosines with u_T_perp, u_S_perp and u_GI_perp, each with a null p from 2,000 sign-flip axes and an interval.
- 'RSI-aligned': p <= 0.01, corrected |cos| >= 0.25 with u_T_perp, and the same sign on u_S_perp.
- 'GI-aligned': the same criteria with u_GI_perp.
- 'RSI-specific': RSI-aligned, and cos(u_crit, u_S perp to GI) - cos(u_crit, u_GI perp to S) has its interval above 0.
- 'Generic attractor': neither aligned, and the random-start loops share the mode.
- Alignment is reported per block against delta, in the R3 form.

R5 Persistence vs self-sustainment.
- The persistence line (rel = 0.5, i.e. SNR = 1, which depends on N) and the self-sustainment line (g = 1) are reported separately.
- 'Direction persists but the loop does not sustain itself' if rel >= 0.5 and the gain's upper bound is < 1.

Toy (4 seeds per cell).
- P1 Phase per cell:
  - 'meta': >= 3 of 4 seeds have B2_meta > 0.10;
  - 'no meta': level 1 reached and <= 1 of 4 seeds in meta;
  - 'no level 1': < 3 of 4 seeds reach held-out 0.95 within 2,000 updates;
  - otherwise 'boundary'.
- P2 Boundaries w_on(W) and w_off(W) by a bracket rule: the interval between the last grid wd with <= 1/4 of seeds in meta and the next with >= 3/4 (switch-off mirrored). wd = 0 counts as the lowest point, with 'below/above grid' flags. Point estimate: interpolate the meta share at 0.5. Simulated: switch found 0.86-0.98, bracket coverage 0.85-0.98 for sharp switches and about 0.7 for soft ones. A seed bootstrap of the mean was tested and under-covers (0.49-0.77), so it is not used.
- P3 'Boundary transfers across width (muP)' if the brackets at W 64, 256 and 1024 overlap; 'shifts' if they are disjoint, with the direction.
- P4 'delta is the geometric control variable' if the delta_h2 values at the switch-on brackets overlap across widths while the wd brackets do not. The susceptibility peak (between-seed SD) is reported with its location (simulated within one grid step of a boundary in about 0.95 of runs for sharp switches).
- P5 PC: 'PC equals BP in the beta -> 0 limit' if |B2_PC(0.03) - B2_BP| < 0.05 with paired seeds. beta_c is the bracket of the level-1 failure. A PC effect on the meta level is claimed only at beta values that pass G4.

A temperature correlate of the "environmental conditions" would suffice, together with the geometry or parameters that model the dynamics of a self-referential "theta" network (theta as in Q-learning, generalised). FINAL REVISED DESIGN (theta / temperature phase diagram; frozen before any sweep; builds on the main plan's frozen loops)

What it delivers, in the user's terms:
(a) Temperature correlate. Two gains measured against sampling temperature at a fixed push:
- G(T), for the self-steering loop;
- K(T), the convention-free carry gain of the natural in-context (KV-cache) loop.
Plus a critical temperature T_c where either gain crosses 1, or the margin by which it stays on one side over the range.
(b) Geometry of the "theta-singular network", per block (delta):
- the top mode of the push-to-read-back operator J and its modal gain;
- onset type (soft or hard) and rotation (complex pair);
- the mode's alignment with the RSI axis (and the GI axis, if the RGI design has frozen one);
- how all of these change with delta.
(c) Toy: a self-training theta loop with a real temperature axis, and its critical tau against delta, width and weight decay.

The per-block result in the user's form: "At push alpha_0, the self-steering gain is G(T) (slope ...). It crosses 1 at T_c = ... [90% interval], or stays below/above 1 by ... over [0.3, 1.0]. The model's own text carries K(T) = ... of its stance into the next turn. The critical mode is RSI-aligned / GI-aligned / generic, with soft/hard onset, and this changes with delta as ..."

1 THEORY (keeps the design's sections 1-8 except where noted)
1.1 Kept as designed:
- F is odd by construction, and zero push gives identical texts;
- the U-statistic noise floor;
- the rotation-cosine switch between projected and norm gains;
- the split between persistence and self-sustainment.
Added: the +/- construction keeps only the odd part. A one-sided self-steering system also feeds back the even part E(v) = E[(x+ + x-)/2] - x0 = O(|v|^2), so its generic bifurcation is transcritical. Report E at T 0.7 (free) and its cosine to u*.
1.2 Linear response: J = Cov_T(x, S)/(T cbar) holds exactly. Drop the Curie reading. Cov_T is O(T) as T goes to 0, so lambda(T) stays finite (sim B: 2.63/2.20/1.50). The T-dependence is empirical. T also sets the radius of the linear regime.
1.3 Two loops, two gains.
- (i) Self-steering map v_(n+1) = F(v_n)/cbar, with secant gains G (norm) and g (projection). G = 1 is the threshold of this map under its read-out/write-in convention. Only these are convention-free: the mode direction, the sign of dG/dalpha, and relative changes of G with T and block.
- (ii) The in-context loop: the unsteered model continues after its own steered text. K = stance carried into turn 2 / turn-1 stance, both read identically. K is unit-free.
This replaces the claim that the self-steering map "is the KV-cache form".
1.4 Persistence: the normalised loop is a noisy power iteration.
- The ordering transition is at L/nu = 1, where rel goes to 0.
- rel >= 0.5 is equivalent to L/nu >= sqrt(2), i.e. a measured SNR of at least 1; this depends on N.
- G = 1 does not depend on N.
- With jump noise, the finite-N self-fed loop is a branching process. Below G = 1 it goes extinct (there is no stationary floor), and G = 1 is the critical branching ratio.
1.5 "Theta-singular" and TD.
- The closed-loop response to an external push b is (I - J)^-1 b. It becomes singular when an eigenvalue of J reaches 1.
- TD analogue: zero-reward pure bootstrapping with full replacement, theta_(k+1) = M theta_k (Baird: zero rewards, divergence through function approximation). Stability requires rho(M) < 1.
- Mapping: theta = the push (or KV state, or weights); step size / trust in own targets = alpha; Boltzmann tau = T, through the (1/tau)Cov term of a Boltzmann-average target (expected SARSA; Asadi & Littman's multistability; log-sum-exp backups are non-expansions); minibatch = N pairs.
- There is no discount-induced contraction, so there is no on-policy guarantee; drop the off-policy leg of the deadly-triad mapping.
- Weight decay acts as A + lambda*I only in bootstrapped updates (T5, not T1).

- M_n = A_n(true) - A_n(wrong);

- "self-improving": S > 0.05;
- "bistable": M_6 > 0.1 and kappa >= 0.8;
- "dissipative": M_6 < 0.1.
